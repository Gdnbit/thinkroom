# 体验 ThinkRoom

[首页](../README.md) · [English](DEMO_EN.md)

用三份示例资料比较一家小店试点 AI 客服的不同方案。

## 导入资料

按[快速开始](../README.md#快速开始)启动 ThinkRoom。打开[问答工作台](http://127.0.0.1:5173/chat)，选择 **上传资料**，导入以下三个示例文件。

| 资料 | 重点 |
| --- | --- |
| [从小处开始](../examples/demo-perspectives/01-small-pilot.txt) | 从高频、低风险的问题开始 |
| [先确认边界](../examples/demo-perspectives/02-data-risks.txt) | 评估隐私、回答准确率和维护成本 |
| [店主笔记](../examples/demo-perspectives/03-own-notes.txt) | 梳理常见问题，区分公开规则和订单信息 |

## 提问

| 模式 | 可以试试 |
| --- | --- |
| **普通问答** | 三份资料各自强调什么？每条观点来自哪里？ |
| **简报生成** | 如果下周开始试点，先覆盖哪些问题？需要验证什么？ |
| **委员会讨论** | 从试点速度、隐私和维护成本三个角度比较这个方案。 |

展开回答中的 **参考资料** 查看引用。可保存的回答会提供 **保存判断**，之后在 **复盘** 中记录实际结果。

## 模型配置

Mock 模式使用示例响应，可以直接体验工作台。使用实际模型时，通过密钥管理工具给后端进程提供 `OPENROUTER_API_KEY`，启动时去掉 `--mock`。调用可能产生费用并发送相关资料给所配置的模型服务商。
