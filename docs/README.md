# Documentation

- [Getting started](../README.md): isolated local setup and synthetic demo.
- [Release preparation](PUBLIC_RELEASE.md): source boundaries and validation.
- [Third-party notices](../THIRD_PARTY_NOTICES.md): dependency and distribution scope.
- `specs/`: technical contracts; historical dates do not establish current acceptance.
- `architecture/`: technical designs, including experimental directions.
- `operations/`: operator references, not production-release approval.

Private journals, original images, research documents and historical verification
reports are excluded. Generate new evidence with synthetic data; never present an
excluded historical report as a new pass.
