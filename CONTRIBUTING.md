# Contributing

Keep changes focused. Describe the problem, behavior, validation and remaining limits.
Use synthetic inputs. Never commit credentials, private research, user databases,
uploads, backups, original screenshots or exported conversations.

Run the README's offline backend tests, frontend lint/type/unit/build checks and
source integrity check. Live-model tests incur cost and require explicit execution.
Preserve selected-source scope, evidence freshness, recoverable citations and
DecisionSnapshot/Outcome/Replay contracts. Do not weaken guards to pass tests.

Original contributions are submitted under Apache-2.0 unless otherwise agreed.
Record external provenance and retain upstream notices. Follow SECURITY.md for
sensitive findings.
