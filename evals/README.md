# Evaluation Map

Evaluation suites are executable contracts, not general product-accuracy claims.

| Suite | Status | Purpose |
|---|---|---|
| `decision-quality/` | Current engineering contract | Grounding, citation, scope, time, conflict, and abstention |
| `structured-workflow-quality/` | Current local v0.1 contract | Briefing and optional committee material-field evidence |
| `ingestion-quality/` | Current reference contract | Approved corpus format/content/flow checks |
| `ingestion-reliability/` | Reference | Generated queue and parser reliability cases; production transport deferred |
| `production-readiness/` | Deferred historical contract | Schema and release safety cases, not current release approval |

Current acceptance evidence is indexed in `docs/verification/EVIDENCE_INDEX.md`. Passing an
engineering suite does not establish financial accuracy or production readiness.
